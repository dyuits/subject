🌸 Firebase 초기 설정

학생 데이터를 Firebase Realtime Database에 업로드하고
관리자·수정 비밀번호를 설정합니다. 최초 1회만 실행하세요.

⚠️ 주의: 이 페이지는 js/firebase-config.js에 실제 Firebase 설정값이 입력된 후에 사용하세요. YOUR_API_KEY가 그대로라면 작동하지 않습니다.
1 Firebase 설정 확인

js/firebase-config.js를 열어 Firebase Console에서 복사한 실제 값으로 교체하세요.
apiKey, authDomain, databaseURL, projectId 등 모두 필요합니다.

2 Firebase 보안 규칙 설정

Firebase Console → Realtime Database → 규칙 탭에 아래 규칙을 붙여넣으세요:

{"rules":{"students":{".read":true,".write":false},"selections":{".read":true,".write":true},"config":{".read":true,".write":false}}}

※ 초기 설정 후 config의 .write를 false로 변경하세요.

3 비밀번호 설정

관리자 비밀번호와 학생 수정 PIN을 입력하세요. SHA-256으로 해시되어 Firebase에 저장됩니다.

4 데이터 업로드

버튼을 클릭하면 197명의 학생 데이터와 설정값이 Firebase에 업로드됩니다.
